3 Paste into your email client

Outlook for Windows (Microsoft 365)

  1. Open Outlook → File → Options
  2. Click Mail → Signatures…
  3. Click New, give it a name (e.g. "WN Shipping")
  4. In the signature edit box, paste this preview directly from step 1 (select the signature above with mouse → Cmd/Ctrl+C → paste here)
  5. Set as default for New messages and Replies/forwards
  6. OK to save

Outlook for Mac

  1. Outlook menu → Settings → Signatures
  2. Click + to add a new signature
  3. Select the signature preview above (click and drag across it) → Cmd+C
  4. Click into the signature editor → Cmd+V
  5. Name it "WN Shipping" → Save
  6. Set as default in Choose default signature

Apple Mail (Mac)

  1. Mail menu → Settings → Signatures
  2. Pick your email account on the left → click +
  3. Select the signature preview above (click and drag) → Cmd+C
  4. Click in the signature editor on the right → Cmd+V
  5. Important: uncheck "Always match my default message font"

Gmail (web)

  1. Gear icon (top right) → See all settings
  2. Scroll down to Signature section → Create new
  3. Select the signature preview above (click and drag) → Cmd/Ctrl+C
  4. Click into the Gmail signature editor → Cmd/Ctrl+V
  5. Set "Signature defaults" for new emails + replies/forwards
  6. Scroll to bottom → Save Changes

Outlook Web (outlook.office.com / outlook.live.com)

  1. Gear icon (top right) → View all Outlook settings
  2. Mail → Compose and reply
  3. Scroll to Email signature
  4. Select the signature preview above → copy → paste into the editor
  5. Tick "Automatically include my signature on new messages" + "on replies"
  6. Save
